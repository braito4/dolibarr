# ONLINE APPOINTMENT FOR [DOLIBARR ERP CRM](https://www.dolibarr.org)

## Features

Provides an online appointment booking system. This allow anyone to book rendez-vous, according to predefined ranges or availabilities.

## Structured calendar availability

BookCal does not persist the slots generated by a structured calendar. A
calendar can be assigned a reusable resource time mask. The mask defines how
time is traversed and rendered, while actual occupations and their quantities
remain independent records.

The same mask can be assigned to several resources. For example, an office
mask can be shared by several rooms and a noon-to-11:59 hotel mask can be
shared by every room in a hotel. Slots are expanded only when requested.
